JOSHUA & KEMI WEDDING WEBSITE

Files:
- index.html (main website)
- style.css (design)
- script.js (countdown)
- images/ (the four supplied wedding photos)

PUBLISH WITH GITHUB PAGES:
1. Create a NEW public GitHub repository, for example joshua-kemi-wedding.
2. Extract this ZIP file on your computer.
3. Open the repository and choose Add file > Upload files.
4. Upload index.html, style.css, script.js, and the entire images folder.
   Important: upload the contents of this folder, not the ZIP file itself.
5. Scroll down and click Commit changes.
6. Open Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select main and /(root), then click Save.
9. Wait a few minutes and refresh Settings > Pages. GitHub will show the live website link.

The venue map button searches Google Maps for the church address supplied.
The countdown uses Nigeria time (UTC+1).
